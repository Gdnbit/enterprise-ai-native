## 1. 状态语言

- **当前已确认方向**：本项目初始化与本次用户任务明确要求。
- **历史明确表达**：可回溯到用户在历史对话中的意向或要求；不自动表示完成实施或不可更改的战略。
- **历史文档原则**：早期设计资料已沉淀原则；归因到该文档，不假称每句都经过用户逐项批准。
- **研究结论**：研究者解释与历史市场快照，不是产品批准。
- **探索设想/待验证假设**：机制、商业或产品可能性，必须验证。
- **本次整理建议**：为了组织知识而增加的实验/维护方法，不是历史用户决策。

## 3. 早期设计资料长期原则 D27–D52

以下全部来自 S01 第 2 节。编号保留便于对照；“长期原则”是源文件状态，不是本项目每项实现都已批准。

| 原编号 | 核心原则 | 迁移解释 |
|---|---|---|
| D27 | Prompt 是 Policy，Harness 是 Tooling | 领域语义、Context、流程、权限、来源和 Eval 更持久 |
| D28 | Business Context scoped/persistent/governed/temporal | 不等于聊天 Memory 或向量知识库 |
| D29 | 大 Context Window 不取消 Runtime | 仍要选择、投影与治理 |
| D30 | Personal/Role/Organization 连接不合并 | 私人 Context 不被组织吞并 |
| D31 | Personal Agent 可是 Router/Trust Boundary | 不要求持有全部领域数据 |
| D32 | 岗位 Context 随岗位，Person Context 随人 | Context Binding 与离职撤权是长期模型 |
| D33 | Context 与 Attention 两个调度问题 | AI 应知与人应注意分开 |
| D34 | 工作生活边界可部分技术化 | 最小必要投影，不传无关私人原因 |
| D35 | 用户操作 Intent 而非 Channel | 渠道保留来源，不自动接管账号 |
| D36 | Message 成为事件/Evidence | 抽取承诺、时间和状态，非仅聚合 Inbox |
| D37 | 外部通信受 Authority/渐进自治控制 | 写得出回复不等于有权作承诺 |
| D38 | Report 是 Projection | 先维护事实与状态，再生成报告 |
| D39 | Observability 不等于绩效 | 不用数字痕迹自动评价人 |
| D40 | SaaS 可作为 Sensor/Actuator | 不要求第一天重做 ERP/OA/CRM |
| D41 | General Agent 可替换，领域状态需权威 | BYOA / Agent-neutral 是方向 |
| D42 | 不把 Prompt/Harness/MCP/UI 当强护城河 | 真正壁垒仍需真实业务证据 |
| D43 | 从真实 Wedge 进入 | 不直接销售抽象平台 |
| D44 | Top-down 与 Bottom-up 兼容 | 入口由资源与真实机会决定 |
| D45 | 组织化由真实网络价值触发 | 不自动合并私人 Context |
| D46 | 早期客户商业模式已验证 | 客户画像仍需市场检验 |
| D47 | 区域策略追求低竞争高价值 | 不能以竞争少推导值得进入 |
| D48 | 计价尽量靠近 Work/Outcome | 没有确定价格或单一收费模式 |
| D49 | 价值扩张来自使用范围扩张 | 不主观涨价 |
| D50 | 每家交付应降低下一家成本 | 观察实施工时与资产复用 |
| D51 | FDE 是交付方式，不默认终局 | 设计知识转移、退出与产品反馈 |
| D52 | 资料/工具库 + 壳子 + 行业迁移 + 定制 + 沉淀 | 本仓按此母结构整理，非机械复制 |

## 4. 更早边界如何延续

S14 的 D18–D26 明确单节点价值优先、Context sovereignty、signal ≠ content、接收节点最终 Attention 决策、Shared Artifact 优先、逐步组织化、Role 与 Person 分离、最小打扰和不抢跑平台化。其 D5、D11–D12 提供确定性业务授权、事实/推断分层、Shared Capability 可替换的依据。

这些约束帮助解释长期愿景，但不把早期垂直项目的 PWA、Pydantic AI、QG/BCG、R1 manifest 或具体实现搬成本项目已定技术方案。

## 5. 不应误写成决策

- 采购单作为首个 MVP、固定四对象模型等是历史助手建议，未查到正式选择。
- 公司将成为 Context Platform/Control Plane，早期 B+A、积累 C、长期 E，是商业工作假设。
- Open-core、具体价格、区域 SME 为最优市场、跨行业优于单行业，均未验证。
- 人员自然形成组织、稳定涌现阈值、Role Agent 重塑招聘、周报/周会大面积消失，是远期推演。
- 自动外发、私人消息接管、员工监控、跨 Context 计算和企业级写入，不因讨论出现而获准。
- 多仓路线不代表已建新仓或已批准额外项目。
