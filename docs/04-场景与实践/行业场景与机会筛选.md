# 行业场景与机会筛选

状态：候选入口与研究问题；没有确定首个行业、客户或订单。依据：S01 D43–D47、S04 §4–8、S08 §26–28，以及历史对话 H06–H08。

## 1. 选择规则

入口可由可获得的业务访问、可信关系和真实痛点决定，重复模式决定长期产品化方向。不要把“认识某行业的人”写成已获得客户授权，也不要把跨行业探索变成每家重做一套。

优先理解：谁实际做事、谁付钱、谁能授权、当前如何完成、卡在哪里、频率/耗时/错误成本、是否有预算、数据能否合法取得。场景候选并不授权接入真实企业数据。

## 2. 候选场景矩阵

| 候选领域 | 可研究的工作闭环 | 主要 Context | 需要验证 | 主要边界 |
|---|---|---|---|---|
| 项目交付/工程 | 需求变更 → 承诺 → 交付 → 验收 | 项目、版本、依赖、负责人、证据 | 人工同步和延期成本是否显著 | 不自动承诺交期/验收 |
| 物流 | 异常发现 → 跟进 → 处理 → 回执 | 运单、节点、异常、责任、沟通 | 异常信息是否可及时获得 | 地点/联系人最小化，系统准入 |
| 设备租赁 | 询租 → 可用性 → 交付/归还 → 状态确认 | 设备、时段、租约、维护 | 重复录入与资产状态错漏 | 价格、合同、赔付由授权者决定 |
| 贸易/销售 | 询单 → 报价草稿 → 确认 → 履约跟进 | 客户需求、商品规则、承诺、订单 | 需求抽取与跟进是否有价值 | 不把模型草稿当报价承诺 |
| 制造/运营 | 事件 → 协同处理 → 复核 → 关闭 | 工单、设备、流程、质量证据 | 系统间交接和返工瓶颈 | 不自动操作安全关键设备 |
| 通用中小企业 | 客户/任务/项目状态 → 协调 → 报告投影 | 组织、角色、流程、业务记录 | 是否存在高频且可度量的协调税 | 不演化为员工监控 |
| 教育职业节点 | 记录 → 未闭环状态 → 跟进证据 | 人、事件、时间、事项 | 单人净负担是否降低 | 旧 R1 独立；不迁移未成年人数据 |

表中工作闭环是基于历史领域候选的本次研究拆解，不是用户选定需求或已有实施案例。行业名不代表客户名单或销售资源。

## 3. 高价值入口与失败信号

历史 ICP 假设是商业模式已验证、有支付能力、仍在增长且协调复杂度上升的企业。区域/非一线策略追求需求与支付能力匹配，而非单纯竞争少或价格低。

拒绝用“AI 新鲜感”代替业务价值；不把客户自身商业模式试错混为改造 ROI；警惕无法界定责任、数据长期不可得、每个客户都需重写、维护成本超过持续收益等情形。[S04 §7–8、23]

## 4. 新业务机会假设

10 月 24 日历史讨论提出：传统企业因人力/组织成本不划算而放弃的细分业务，可能在 AI 成本结构下值得重新评估。此处是待验证假设，不是“AI 必然让小市场盈利”的结论。[H08]

建议同时测需求规模、可收费单位、获客成本、人工兜底、模型及连接器成本、例外比例和合规成本；不能只算 token 成本。若仍无法持续交付正向价值，则否定该入口而非扩大平台叙事。
