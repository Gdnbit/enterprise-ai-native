# 知识库维护与公开发布规范

更新：2026-11-06。本文用于维护公开文档的来源、状态、隐私和验证边界。

## 1. 内容与证据

- 区分项目已确认方向、历史设计原则、外部公开事实、厂商自述、研究建议、待验证假设与实际测试结果。
- 关键论述注明来源、日期、适用范围和局限。公开外部事实优先链接一手材料；项目设计记录不充当外部验证。
- 各文档族分别维护来源编号，详见[来源索引](来源索引.md)。综合摘要不替代其所引用的公开研究。
- 新决定同步更新[状态登记](../06-决策与研究/整合决策与待验证假设.md)、受影响方案及[导航](../../SOURCE_OF_TRUTH.md)，保留被替代关系。

## 2. 隐私与传播

- 不收录凭据、认证材料、私人生活细节、客户名单/联系人、合同正文、真实业务记录或未成年人数据。
- 不分发原始讨论、私人消息链接、私有仓库地址或提交标识、个人迁移资料、本地绝对路径和无关身份信息。
- 行业案例只使用公开可引用材料或经明确批准的泛化内容。泛化不等于可以披露可识别的客户事实。
- 发布前检查全部文件、提交元数据、分支和 PR；只清理最新文件不能消除历史泄露。
- 客户项目经验的复用须有合法权利，不能默认取得客户原始数据或知识产权。

## 3. 许可与第三方材料

本仓库由维护者有权许可的原创文档采用 [CC BY-NC 4.0](../../LICENSE)。未经另行授权不得将这些受许可内容用于商业目的。第三方引用、数据、商标及链接目标不因此被重新许可，详见[权利与使用说明](../../RIGHTS.md)。

复制、改编或引入第三方文件前检查精确版本、许可、署名、用途限制及相互兼容性。单纯可在网页阅读不等于获得再分发或商业使用权。

## 4. 修改与验收

- 优先可审阅的小幅变更；新文件使用 UTF-8 无 BOM、LF 换行。
- 检查相对链接、页内锚点、来源编号、冲突标记、许可声明和当前状态。
- 内容扫描与人工审查并用；不得把模式扫描解释为完整安全审计。
- 草稿 PR、文件上传、main 更新、公开可见性和部署是不同结果，各自需要核实。
- 只有读取远端确切提交和文件后才报告同步完成；没有运行 CI、应用构建或客户试点时，不能宣称相应测试通过。

## 5. 当前公开版范围

本版保留通用研究、方案与设计原则，未包含未合并研究和离线实验代码，也未分发客户项目或原有 Git 历史。公开材料不是生产运行许可、客户操作授权、合同承诺或安全保证。
